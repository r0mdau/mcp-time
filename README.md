# MCP Time Server

A small Go [MCP](https://modelcontextprotocol.io) server that provides time and timezone conversion tools over HTTP.

Based on the Python [MCP Time Server](https://github.com/modelcontextprotocol/servers/tree/main/src/time) from [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers).

## Tools

| Tool | Parameters | Description |
| --- | --- | --- |
| `get_current_time` | `timezone` (IANA name, e.g. `Europe/London`) | Current time in the given timezone. |
| `convert_time` | `source_timezone`, `time` (24-hour `HH:MM`), `target_timezone` | Converts `HH:MM` on today's date in the source timezone to the target timezone. Also returns the offset between the two (e.g. `+9.0h`). |

Notes:

- The tool schema marks `timezone` as required, but the handler falls back to `UTC` if it is empty. All three `convert_time` parameters are required.
- The detected local timezone (or the `--local-timezone` override) is written into the parameter descriptions, so clients know which zone to use when the user does not name one.
- Results contain `timezone`, an ISO 8601 `datetime` (second precision), `day_of_week` and `is_dst`. `convert_time` returns these as `source` and `target`, plus `time_difference`.

Example prompts (e.g. in GitHub Copilot):

- `Get the current time in New York using the MCP Time Server tool.`
- `Convert 14:30 from London time to Tokyo time using the MCP Time Server tool.`

## Usage

Requires Go 1.24 or later (see `go.mod`).

```bash
make build   # format, vet, and compile to build/mcp-time
make run     # build, then start the server with default flags
```

Or run the binary directly with options:

```bash
./build/mcp-time --port 9000 --local-timezone Europe/Paris
```

| Flag | Default | Description |
| --- | --- | --- |
| `--port` | `8080` | Port to listen on. |
| `--local-timezone` | system timezone, or `UTC` if it cannot be detected | IANA timezone to report as the local one. |

### Connecting a client

The server uses the MCP streamable HTTP transport. Point your MCP client at `http://localhost:8080/` (adjust the port if you changed it). The handler is mounted on the server root and is not restricted to a specific path.

### Security

The server has **no authentication** and is intended for local use only. It listens on all network interfaces (`:<port>`), not just loopback, so block the port with a firewall or run it only on a trusted network. Do not expose it to the internet.
